# CSV Quick Check

[Use the free tool](https://hellofuturetechnologies.github.io/csv-quick-check/)

Check UTF-8 tabular files locally in your browser. Choose a CSV, select its separator, and click **Check file**. You can also use **Load example** without a file.

- Counts data records, columns, and blank cells.
- Shows blank counts and percentages per column. Whitespace-only cells count as blank.
- Flags exact duplicate parsed rows and shows up to 100 record references. Duplicates are compared without trimming or case conversion.
- Handles quoted separators, escaped quotes, multiline fields, and common line endings.
- Reports malformed rows, invalid UTF-8, and blank or repeated headers.

Files are limited to 10 MiB. The first record must contain headers. No files are uploaded and the tool does not modify the input.

Open `index.html` to run a local copy. No build or dependencies are required.
